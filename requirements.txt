# --- Sobre las versiones (Roadmap #16.9) -------------------------------------
# Cada línea lleva un mínimo (la versión con la que esto se ha probado) y un

# cualquiera puede traerse un cambio incompatible —Flask 4, gunicorn 27— y
# enterarse uno cuando el servidor no arranca; sin el mínimo, arrastra parches de
# seguridad ya publicados.
#
# Esto NO es un candado exacto: para reproducir la máquina tal cual está, en el
# servidor se hace
#
#   pip freeze > requirements-lock.txt
#
# y ese archivo es el que reconstruye el entorno idéntico. Aquí van los rangos
# porque son los que Dependabot (.github/dependabot.yml) sabe subir solo cuando
# sale una versión con un CVE.
